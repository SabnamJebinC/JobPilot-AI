# JobPilot AI

## Project Overview

JobPilot AI is a Python-based job description analyzer.

It compares technical skills required by employers
with the skills listed in a candidate profile.

## Features

- Technical skill extraction
- Skill matching
- Missing skill identification
- Keyword match percentage
- Input validation

## Technologies

- Python
- Regular Expressions
- Google Colab

## Project Files

- app.py
- jobpilot_tools.py
- sample_profile.py
- README.md

## How to Run

Install Python 3.

Open a terminal in the project folder.

Run the following command:

    python app.py

## Example Output

Candidate: Alex Morgan, 
Job Title: Python Backend Developer, 
Keyword Match: 33.33%

## Limitations

- Keyword coverage is not a hiring probability.
- Only supported technical skills are detected.
- The demo uses fictional candidate data.
- JobPilot AI does not automatically apply for jobs.
